TMT Wrapup Lead — Reviewer Sandbox

This page is a web-based sandbox that uses the same App ID and requests the same permissions (pages_show_list, pages_read_engagement, pages_messaging, business_management) as the production Windows desktop application. It is provided so reviewers can test permissions in a browser without installing desktop software.

Step 3 — Optional: find a Page via Business Manager ID (business_management)

Pages that a user manages through a Business Manager / Business Asset Group (rather than as a direct Page admin) are not always returned by /me/accounts above. This fallback looks up Pages owned by a specific Business Manager instead.
