TMT Wrapup Lead — Reviewer Sandbox

This page is a web-based sandbox that uses the same App ID, requests the same permissions (pages_show_list, pages_read_engagement, pages_messaging, business_management) and lists Pages with the same logic as the production Windows desktop application. It is provided so reviewers can test permissions in a browser without installing desktop software.

Step 1 — Log in with Facebook

In the Facebook dialog, select the Business(es) and every Page you want to connect. business_management is used only so that Pages owned by a Business Portfolio are returned by /me/accounts. This app never creates, edits or deletes anything in Business Manager and never calls any /{business-id} endpoint.

Not connected.
Optional — Compare without business_management

Removes only the business_management permission from this app, then lists Pages again with the other three permissions. Pages owned by a Business Portfolio are missing or incomplete in this mode. Click "Continue with Facebook" afterwards to grant business_management again and see the full list.
