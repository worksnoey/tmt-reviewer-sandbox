TMT Wrapup Lead — Reviewer Sandbox

This page is a web-based sandbox that uses the same App ID, requests the same permissions (pages_show_list, pages_read_engagement, pages_messaging, business_management) and lists Pages with the same logic as the production Windows desktop application. It is provided so reviewers can test permissions in a browser without installing desktop software.

Step 1 — Log in with Facebook

In the Facebook dialog, select the Business(es) and every Page you want to connect. business_management is used only so that Pages owned by a Business Portfolio are returned by /me/accounts. This app never creates, edits or deletes anything in Business Manager and never calls any /{business-id} endpoint.

Not connected.
Optional — Compare without and with business_management

business_management takes effect in the Facebook Login dialog: it adds a step to select Businesses, so Pages owned by a Business Portfolio can be granted to this app. Removing it later does not remove Pages already granted, and adding it later on top of an existing login does not grant all of them. Each login below therefore starts after A.

A. Remove all of this app's permissions for your account. This also disconnects the desktop app for this account until you connect again.
B. Log in without business_management. The Login dialog has no Business step, and Pages owned by a Business Portfolio are missing from the list.
Click A again, then:
C. Log in with business_management. Select every Business and every Page in the Login dialog to see the full list.
